# Vayal Vimaani

Standalone farmer-first website for Vayal Vimaani, focused on practical agricultural drone spraying, field support, subsidy guidance, and simple booking actions.

## Development

```bash
pnpm install
pnpm dev
```

Run the validation commands before delivery:

```bash
pnpm check
pnpm build
```

The standalone app renders at `/` and does not depend on Raphael Drones routes. The Raphael Drones site remains in its original project directory. App-store buttons are intentionally placeholders until official listings are supplied. Government support language is informational and avoids promising approval or eligibility.
